# Full-stack setup

The maintained setup guide is the [root README](../README.md).

```sh
make init
make dev
```

For host tools and CI checks, run `make setup`, `make check`, `make test` and
`make build`. Use [backend development](README_backend.md),
[frontend development](../frontend/README.md) and [deployment](deployment.md)
for detailed instructions. Local secrets belong in the ignored root `.env`.
