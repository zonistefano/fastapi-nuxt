# Template background

This repository combines a FastAPI/SQLModel backend and a Nuxt frontend.
It has its own uv/Bun toolchain and Compose configuration. Follow the
[root README](../README.md) when creating or running a project.

The upstream [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template)
is useful background, but its commands and deployment configuration do not
apply directly to this repository.
